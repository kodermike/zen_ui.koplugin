## Overview

KOReader gives access to its native menus and document settings within Zen Settings. Available tools depend on whether you are browsing books or reading one.

## Menus and layout

If accessed from the library, just like in KOReader, the menu contains File browser, Settings, Tools, Search, and Main menu. While reading, it contains Navigation, Typesetting, Settings, Tools, Search, and Main menu.

The menus use KOReader's existing settings, including installed plugin entries.

For book layout controls, open **Typesetting > Document settings > Layout**. Available options depend on the document format. Hold a preset to save it as a default. Numeric selectors retain their Apply, default, and extra actions; leaving a selector without applying preserves the previous setting.

Text entry and confirmations use compact dialogs. Complete tools and custom plugin screens keep their existing interfaces. The original KOReader top menu remains available with its existing visibility preferences.
